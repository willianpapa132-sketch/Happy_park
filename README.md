# 🎉 Happy Park

Site institucional desenvolvido para o **Happy Park**, com foco em apresentar o espaço, as decorações disponíveis e facilitar o contato com clientes interessados em realizar festas e eventos.

## 🔗 Demonstração

**Acesse o projeto:**

https://happy-park-lovat.vercel.app/

---

## 📖 Sobre

Este projeto foi desenvolvido utilizando HTML, CSS e JavaScript puro, priorizando desempenho, responsividade e uma interface moderna.

O objetivo é fornecer uma experiência agradável para o usuário, permitindo conhecer o espaço, visualizar decorações e solicitar orçamentos de forma simples.

---

## ✨ Funcionalidades

- Página inicial com apresentação da empresa
- Seção de decorações
- Página do espaço para eventos
- Layout totalmente responsivo
- Navegação intuitiva
- Botão de contato via WhatsApp
- Galeria de imagens

---

## 🛠️ Tecnologias
